# Лабораторная работа 7

## Вариант 10. Перевод чисел от 1 до 13 в слова

### Постановка задачи

Необходимо разработать программу, которая принимает на вход целое число в диапазоне от 1 до 13 и выводит его текстовое представление на русском языке.

Если пользователь вводит число, выходящее за рамки указанного диапазона, или некорректные данные (например, буквы), программа должна вывести сообщение об ошибке.

Для реализации логики перевода необходимо использовать пользовательскую функцию и оператор ветвления `switch-case`.

### Описание работы программы

1. Программа запрашивает у пользователя ввод целого числа от 1 до 13.
2. С помощью функции `scanf` выполняется проверка на корректность ввода. Если введены буквы или символы, срабатывает блок `else` с предупреждением.
3. При корректном вводе управление передается в функцию `printNumberInWords(int num)`.
4. Внутри функции оператор `switch` последовательно сопоставляет переданное число со значениями `case`. Каждый успешный выбор завершается оператором `break`.

### Тестовые примеры

| Входные данные | Ожидаемый результат |
| :--- | :--- |
| `1` | Число словами: один |
| `7` | Число словами: семь |
| `13` | Число словами: тринадцать |
| `15` | Ошибка: число вне диапазона. |
| `abc` | Ошибка: введено некорректное значение. |
